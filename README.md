# Awesome Metamath

Explore explicit proofs, proof databases and independent verification.

## Start here

- [Project and downloads](https://us.metamath.org/) — Start with the FAQ and installation guidance. Choose an axiom system before choosing a database.
- [Metamath Proof Explorer](https://us.metamath.org/mpeuni/mmset.html) — Follow a theorem through its hypotheses and dependencies in the set.mm database.
- [Other Metamath tools](https://us.metamath.org/other.html) — Find independent verifiers and proof-authoring tools. Check their supported database syntax.
- [set.mm source](https://github.com/metamath/set.mm) — Read contribution guidance and inspect the versioned mathematical database.

## First investigation

Choose a short theorem in the Proof Explorer. Identify the axioms it depends on and follow one substitution step. Record the theorem label and database revision.

This is a suggested learning exercise. It has not been execution-tested by this collection.
